UI/Gateway-only source bundle

Is ZIP mein static dashboard aur gateway ke HTML copies, React UI components, required UI styles, app shell, client-side helpers aur unke dependency manifests hain. Reference screenshots aur internal work notes shamil nahi hain.

Backend API implementations, database/auth modules, dynamic server route wrapper aur Railway deployment files is bundle mein jaan-boojhkar nahi hain. Poora runnable/deployable application aur working.zip se byte-matched backend `ohhmyyes-railway-ready.zip` mein hai. UI se API features chalane ke liye full ZIP ka backend saath chahiye.

Visitor gateway mein analytics, camera aur GPS alag-alag opt-in hain. Camera/GPS ke liye visitor opt-in aur browser permission zaroori hai; bina sharing ke continue kiya ja sakta hai.
